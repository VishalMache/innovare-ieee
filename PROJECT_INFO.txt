4. WHAT EACH FILE / COMPONENT DOES
================================================================================

── ROOT LAYOUT (src/app/layout.tsx) ─────────────────────────────────────────
  The root shell of the entire website. Does the following:
  • Loads Geist Sans and Geist Mono as local variable fonts.
  • Sets SEO metadata: page title and meta description.
  • Forces dark mode via "dark" class on <html>.
  • Injects global providers in order: Cursor → PageLoader → SmoothScroll.
  • Wraps content with Navbar (top) and Footer (bottom).

── MAIN PAGE (src/app/page.tsx) ───────────────────────────────────────────────
  Assembles all section components in vertical order:
    HeroSection → LogosStrip → StatsCounter → WhoWeAre →
    ProjectShowcase → Timeline → WallOfFame → Team → FAQ → JoinUs

── API ROUTE (src/app/api/join/route.ts) ──────────────────────────────────────
  Handles POST requests from the JoinUs form:
    1. Validates required fields: name, email, branch, year.
    2. Inserts a row into Supabase `applications` table.
    3. Sends a confirmation email via Resend to the applicant.
    4. Returns { success: true } to trigger frontend animations.
  All keys are pulled from environment variables (with placeholder fallbacks).

── HEROSCENE (src/components/3d/HeroScene.tsx) ─────────────────────────────────
  Pure Canvas 2D animation component. No Three.js — uses raw HTML Canvas API.
  Renders two layers:
    • A radial-gradient "orb" at center-top (glowing blue-white sphere).
    • 220 star particles that orbit the orb in elliptical paths.
  Stars: each has unique angle, orbit radius, speed, size, alpha, twinkle phase.
  Animates via requestAnimationFrame. Fully responsive via ResizeObserver.

── HEROSECTION (src/components/sections/HeroSection.tsx) ────────────────────
  Main hero section. Divided into two columns (grid):
    Left:  Animated headline (Framer Motion fadeIn from below), sub-headline,
           two CTA buttons ("Join Us" → #join, "Explore Projects" → #projects).
    Right: Autoplay muted looping video (ieee-bg.mp4) with mix-blend-mode:screen.
  The HeroScene canvas sits as an absolute background layer behind everything.
  Uses Next.js dynamic() import with ssr:false so the canvas only renders client-side.
  Uses Fallback3D component as Suspense fallback during canvas load.

── CURSOR (src/components/animations/Cursor.tsx) ─────────────────────────────
  Custom cursor that follows the mouse. Detects elements with data-cursor="hover"
  attribute and morphs into a larger state. Adds a premium interactive feel.

── PAGELOADER (src/components/animations/PageLoader.tsx) ─────────────────────
  Full-screen overlay that plays on first load. Fades out after assets are ready.
  Includes a progress indicator or branding animation.

── SMOOTHSCROLL (src/components/animations/SmoothScroll.tsx) ─────────────────
  Wrapper around the Lenis library. Provides buttery smooth inertia-based
  scrolling across the entire page.

── FALLBACK3D (src/components/animations/Fallback3D.tsx) ─────────────────────
  Shown while HeroScene canvas is loading or if WebGL/Canvas is unavailable.
  Provides a CSS-only fallback so the page never looks broken.

── GLOWLAYER (src/components/effects/GlowLayer.tsx) ──────────────────────────
  Ambient radial glow div layered over sections for depth and atmosphere.

── GRAINOVERLAY (src/components/effects/GrainOverlay.tsx) ────────────────────
  SVG/CSS film grain overlay for a premium, textured feel over flat backgrounds.

── NAVBAR (src/components/layout/Navbar.tsx) ─────────────────────────────────
  Sticky top navigation. Contains logo, nav links to page sections, and CTA.
  Likely has scroll-aware opacity/blur effect.

── FOOTER (src/components/layout/Footer.tsx) ─────────────────────────────────
  Site footer: social links, copyright, navigation shortcuts.

── LOGOSSTRIP (src/components/sections/LogosStrip.tsx) ───────────────────────
  Horizontally scrolling marquee strip of tech/partner logos.

── STATSCOUNTER (src/components/sections/StatsCounter.tsx) ──────────────────
  Animated counter section. Numbers count up when scrolled into view.
  Example stats: "50+ Members", "20+ Projects", etc.

── WHOWEARE (src/components/sections/WhoWeAre.tsx) ──────────────────────────
  About section explaining the student branch mission and vision.

── PROJECTSHOWCASE (src/components/sections/ProjectShowcase.tsx) ─────────────
  Displays the team's engineering projects in interactive cards.
  Largest section file at ~9.7KB. Likely includes hover effects, project
  descriptions, tech tags, and links.

── TIMELINE (src/components/sections/Timeline.tsx) ───────────────────────────
  Vertical scroll-based timeline of events, milestones, and workshops.
  Uses GSAP ScrollTrigger for reveal animations.

── WALLOFFAME (src/components/sections/WallOfFame.tsx) ───────────────────────
  Recognition section showing awards, achievements, or notable alumni.

── TEAM (src/components/sections/Team.tsx) ───────────────────────────────────
  Largest section at ~14.2KB. Displays team members in a 3D network arc
  carousel. Members are pulled from src/data/team-members.ts.
  Each card shows: name, role, bio, profile image, initials fallback,
  and optional GitHub/LinkedIn/Twitter links.

── FAQ (src/components/sections/FAQ.tsx) ─────────────────────────────────────
  Frequently Asked Questions using the shadcn Accordion component.
  Smooth expand/collapse with animation.

── JOINUS (src/components/sections/JoinUs.tsx) ───────────────────────────────
  The join/application form section. Uses react-hook-form + Zod for
  validation. Fields: name, email, branch (department), year of study.
  On submit: calls POST /api/join → inserts to Supabase → sends email via Resend.
  Triggers a success animation after valid submission.

6. BACKEND & API
================================================================================

  Endpoint : POST /api/join
  File     : src/app/api/join/route.ts
  Runtime  : Next.js Edge/Node API Route (App Router)

  Flow:
    1. Client (JoinUs form) sends POST with: { name, email, branch, year }
    2. Server validates all 4 fields are present.
    3. Supabase Insert → table: "applications"
       Columns: name, email, branch, year_of_study
    4. Resend Email → sends styled HTML email to applicant:
       From: "INNOVARE IEEE <onboarding@innovare-ieee.org>"
       Subject: "Welcome to the Future - INNOVARE IEEE"
    5. Returns { success: true, data } with HTTP 200.
    6. On any DB error, logs it but doesn't fail the request (graceful).
    7. On email error, logs it but doesn't fail the request.

  Note: No server-side Zod validation currently — only client-side via
        react-hook-form handles validation before the request is made.

10. 3D / CANVAS SYSTEM
================================================================================

  The hero background is a pure HTML Canvas 2D animation (NO Three.js):

  Component   : src/components/3d/HeroScene.tsx
  Stars       : 220 particles
  Each star has:
    - angle     : current orbital angle (radians)
    - orbitR    : orbital radius (20px to 60% of screen)
    - orbitCx/Y : slight offset from orb center for variation
    - speed     : angular velocity (±0.0003 to ±0.0009 rad/frame)
    - size      : particle radius (0.4px to 1.8px)
    - alpha     : base opacity (0.2 to 0.7)
    - twinkle   : phase offset for sine-based flicker

  Orb Rendering:
    - Large radial gradient from white-blue center to transparent edge
    - Small bright core gradient for the inner glow
    - Positioned at top-center (cx=W/2, cy=-H*0.04) — partially off-screen

  Stars use elliptical orbits (vertically squished by 0.55 factor)
  to simulate perspective depth. They orbit in both clockwise and
  counter-clockwise directions randomly.

  React Three Fiber (@react-three/fiber) and Drei are installed as
  dependencies but HeroScene currently uses the native Canvas 2D API.
  They are available for future 3D upgrades or other components.

  Cobe library is installed for a potential interactive globe component.

15. KEY ARCHITECTURE DECISIONS
================================================================================

  ① App Router (not Pages Router)
     Uses Next.js 14 App Router for layouts, nested routing, and server
     components. The /api/join endpoint is a Route Handler (not pages/api).

  ② "use client" Directives
     All animation components (HeroSection, HeroScene, Cursor, PageLoader,
     SmoothScroll, Team) are client components due to browser APIs.
     Static sections may be server components for performance.

  ③ Dynamic Import with SSR:false
     HeroScene is dynamically imported (no SSR) to prevent hydration issues
     with browser-only Canvas API. This is the correct Next.js pattern.

  ④ Fallback Strategy
     Fallback3D.tsx ensures the hero section never looks broken on slow
     connections or browsers with canvas issues.

  ⑤ Graceful API Failures
     The /api/join route handles Supabase and Resend errors separately.
     If one fails, the other still runs. The frontend always gets a response.

  ⑥ Tailwind CSS v4
     Uses the new @import "tailwindcss" syntax (v4 style), NOT the old
     @tailwind directives. Uses @plugin for tailwindcss-animate.
     Custom theme is defined in globals.css using @theme inline {}.

  ⑦ OKLCH Color Space
     Most color tokens use oklch() for perceptually uniform color mixing.
     Primary brand color (#5EA3C1) is kept as hex for clarity.

  ⑧ Data Separation
     Team member data lives in src/data/team-members.ts — fully separate
     from presentation logic. Easy to edit without touching components.

  ⑨ Constants File
     Animation durations centralized in src/lib/constants.ts with strict
     MAX_DURATION of 1.2s to keep the UI feeling fast and responsive.

  ⑩ Single Page Architecture
